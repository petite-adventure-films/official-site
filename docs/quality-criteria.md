# 共通品質基準

## アクセシビリティ

公開サイト・CMSともにWCAG 2.2 レベルAAへの適合を目標とし、A・AAの全達成基準を評価対象とする。
自動検査と手動確認を組み合わせ、各基準の結果と根拠を残す。未確認を適合と扱わない。
ページ全体・一連の操作・画像や動画を含めて評価し、一部の検査結果をサイト全体の適合としない。

参照: [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## 情報公開

公開内容が検索可能で、ページ構造・メタ情報・構造化データが本文の意味と一致していること。
監督の言葉や文脈を歪めず、検索順位やAI回答への掲載を品質の保証条件にしない。
CMSは必要な情報の入力・管理を支え、管理画面や下書きは公開対象としない。

## 内容と表記

内容の出典と解釈を区別し、正式名称・人名・ページ名は確認した表記を使う。
一部の記事で監督の思想全体を代表させず、更新頻度だけで情報の重要度を判断しない。
