# イベント画面の構成

対象 #392。代表編集画面の全体配置と共通構造を確認済み。操作・保存・公開の動作は未検証。

外観・共通構造・選択UIは [CMS UI共通ルール](../../../docs/cms-ui-rules.md)、認証・保存・履歴・プレビューは [CMS共通画面操作](../../002-cms-foundation/contracts/screens.md) に従う。

## 本文の入力

1. 記事タイトル
2. 日時：日付Field、時間の案内
3. 開催場所：開催形式Field、会場情報、開催場所の備考
4. 参加案内：料金、主催者・問い合わせ、イベント全体の備考

日付Fieldは「開催日、複数日にわたるSwitch」の順。オンのときは開催日とSwitchの間に終了日を入れ、同じ行に並べる。日付は年を含め、内容に合う幅で表示する。

開催形式はオフライン／オンラインの複数選択Chip。新規作成時はオフラインを選択済みにする。オフライン選択時は会場名・住所・地図URL・アクセスを表示する。開催場所の備考は開催形式にかかわらず表示し、開催されるところの追加説明やオンラインの参加方法・URLを書ける。イベント全体の備考とは別に保持する。

## 右サイドバー

- 保存・公開：共通画面操作に従う。
- タグ：映画タグ・イベントタグをそれぞれFieldとして並べる。どちらも任意・複数選択。
- 開催状況：独立したSectionとし、延期／中止を選ぶFieldを置く。一度に選べるのは1つ、選択中のChipを再度押すと解除する。未選択は通常開催を意味し、「通常」の選択肢は設けない。

イベントプレビューでは、延期・中止と保存・公開状態を区別する。
