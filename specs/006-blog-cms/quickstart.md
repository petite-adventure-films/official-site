# ブログCMSの実装後検証

対象 #418。設計段階の手順であり、実装・検証済みの記録ではない。

## 前提と起動

設計ゲートと実装範囲が合意済みであること。Node 24.x、pnpm 10.28.2、依存導入済み環境とローカルD1を使う。実装後にリポジトリ直下から実行する。

```sh
pnpm --dir cms run db:migrate:local
pnpm --dir cms run dev
```

表示された開発URLで/cms/blogを開く。現在は未実装。旧データを入れた複製DBでもmigration前後の照合をする。公開確認にはブログ対応の保護された配信先・アダプターが必要。

## 受け入れ確認

| 操作 | 期待結果 |
| --- | --- |
| 未分類・途中入力の保存→再編集 | 本文・未選択・タグ・スイッチを保持 |
| 未分類で公開→カテゴリ選択 | 未分類は項目エラー、既存1件選択で次の検証へ |
| 公開記事の編集・保存のみ | 公開本文・分類・URL・公開日は変わらない |
| event/blog混在で一覧・検索・ページ送り | 記事・検索件数・総件数・編集先が種別ごとに分離 |
| 保存中に追加入力→複製/履歴へ | flushが最新まで完了。失敗は入力を保持して次操作を止める |
| 応答喪失・同一ID再送・別タブ競合 | 重複作成/履歴増加なし、競合を上書きしない |
| 複製・履歴復元 | コピーは新slug/下書き。復元は直前を保護し公開を変えない |
| 固定ページ・他記事・転送予約とslug衝突 | 公開不可。検査後の並行公開でも二重所有しない |
| 日本語/エンコード済みslug・slug変更 | 旧URL保持、二重エンコード・転送ループ・多段転送なし |
| 旧記事の再公開 | 元公開日を保持し、編集/履歴時刻と混同しない |
| 配信失敗・結果不明・再照合 | 現行版保持。不明を成功/失敗と推定しない |

旧データは通常記事、おすすめ、報告、映画/イベントタグ、画像/PDF/内部リンク/動画、未知カテゴリ/未対応本文の例でID・URL・公開日・参照・分類を照合。欠落を成功扱いにしない。資料は2026-08-10時点で、切り替え時は#391で最新データを再照合する。

## 自動・画面検証

```sh
pnpm --dir cms run typecheck
pnpm --dir cms test
pnpm --dir cms run test:e2e
```

種別混在、migration前後、未分類保存/公開拒否、再送・競合、日時、本文参照、URL衝突を優先。既存イベントの保存・公開・履歴も回帰確認。公開側変更時は `pnpm --dir astro run test:e2e` とURL・一覧・メタ情報・WCAG 2.2 AAの対象確認を行う。

PCで共通操作位置、保存状態、必須エラーへの移動、Chip単一/複数選択、Switch、履歴、長い本文と添付表示を確認。実施環境・結果・未確認条件をPRに残す。CMS保存だけでブログ公開を完了にしない。
