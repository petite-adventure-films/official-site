# ブログのCMS編集・公開

対象Issue #418。ブログ固有の要件は合意済み。共通の編集・公開契約を参照して設計へ進む。

## 利用者の操作

- 監督がブログ記事を新規作成し、下書き保存、再編集、公開できる。旧記事も編集でき、下書きを保存しても公開中の記事は変わらない。
- 監督が本文、既存カテゴリ、映画タグ、イベントタグ、おすすめ、ワークショップ報告を管理できる。本文・添付の詳細は #334・#395 と照合する。
- 読者は旧記事と添付に引き続きたどれ、カテゴリ・おすすめ・ワークショップ報告の一覧を利用できる。

## 現行データと引き継ぎ

2026-08-10の `astro/data/wordpress-export.json` を照合。ブログ310件にURL用の `name` とカテゴリがあり、カテゴリは全記事1件ずつ。旧一般タグがある記事は296件、映画タグがある記事は79件、イベントタグがある記事は9件。サムネイル欄は全件 `false`。おすすめは旧データの `recommended === "1"` で27件。

| 項目 | 仕様案 |
| --- | --- |
| タイトル・本文 | 既存本文の画像、PDF、内部リンク、動画への到達を維持する。保存できる編集形式と旧本文の変換方法は #334・#391 で確認する |
| 記事ID・URL | 旧WordPress IDを対応情報として保持する。旧 `name` のルート直下のURLを維持し、固定ページとの衝突とエンコード有無を確認する。新規記事も `/{slug}/` を使う。固定ページ、既存記事、予約済みの転送元と衝突する場合は公開を止める。slugの初期値、設定・変更のタイミング、公開済みURLの転送は共通公開仕様に従う |
| カテゴリ | 現行のカテゴリと記事の対応を保持し、既存のカテゴリのみから選ぶ。CMSでのカテゴリ新規作成は不可。下書きでは未選択でも保存でき、公開時は既存カテゴリから1件の選択を必須とする |
| タグ・作品 | 映画タグとイベントタグを使う。作品はコード管理の定義を参照する。一般タグの編集項目は設けず、旧一般タグの保全とワークショップ報告の移行に必要な対応は #391 で確認する |
| おすすめ・ワークショップ報告 | それぞれ独立したオン・オフのスイッチで設定する。移行時は旧おすすめフラグと、旧一般タグ ID `5026` によるワークショップ報告の分類（8月時点で16件）を対応するスイッチに引き継ぐ |
| サムネイル | サムネイルの編集項目は設けない。本文内の画像は移行・編集の対象 |
| 公開・更新日時 | 旧記事の公開日を維持する。更新日時をどの画面で扱うか確認する |

## 受け入れ条件

- 下書きにした記事は公開されず、開き直したときに本文・分類と2つのスイッチの状態が保持される。再編集して公開するまで公開中の記事が変わらない。
- 未分類の下書きは保存できる。公開するには、既存カテゴリを1件選ぶ必要がある。
- 旧記事のURLを更新後も利用できる。新規記事は `/{slug}/` で公開され、固定ページ・既存記事・予約済みURLとの衝突時は公開が拒否される。移行後の本文と添付リンク、カテゴリ・おすすめ・ワークショップ報告の表示を旧データと照合する。
- サムネイルなし、既存タグあり、添付ありの旧記事の例を用意し、変換と公開結果を確認する。スナップショット取得後の追加・更新は #391 の最終同期で照合する。

## 共通仕様と移行への引き継ぎ

- slugの操作と公開済みURLの転送は、[イベントの公開契約](../002-cms-foundation/contracts/publication.md)を起点に #333・#390 で共通化する。ブログ固有の確認対象は、ルート直下のURL形式と既存URLの維持。
- 本文の編集形式と旧本文の変換・保全は #334・#391 で確認する。
