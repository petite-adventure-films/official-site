## データ対応（2026-08-10取得の21件）

母集団は `astro/data/wordpress-export.json` のchannels。サンプルは `packages/content-schema/samples/content/video.json`（17837）。v1と現行draftは異なる形式であり、直接互換とは扱わない。

| 旧項目 / v1 | 現行編集 | 対応・欠損 |
| --- | --- | --- |
| youtube_id / source.provider + videoId | youtubeId | YouTubeのみ。汎用動画ファイルのアップロードや他配信元の追加は対象外。旧20件は11文字ID、12568のみwatch URL |
| created_year / production.year | productionYear | 旧年表記を文字列で保持。v1は整数だが現行は入力途中・欠損を許容 |
| created_country / production.country | productionCountry | 全件非空。任意入力、欠損を自動補完しない |
| running_time / production.durationSeconds | duration | MM:SSが20件、H:MM:SSが1件（14156=1:10:17）。v1サンプルの3752秒は62:32に対応。編集/表示は原文文字列を保持 |
| content / description | body schemaVersion 2 | v1本文はschemaVersion 1。未知の装飾・添付を黙って落とさない |
| film_tags / filmIds | filmTagIds | 関連あり5件、なし16件。旧term_idを文字列化し登録タグと照合。v1の作品ID体系との対応は正式移行#391 |
| id / slug、published/updated | 元レコードを保全 | 検証コピーの公開日時と旧日時は別。全件の旧日時を正式CMSへ移す作業は#338 |

## 見つけた不具合と修正

検索エンジン向けVideoObjectの上映時間変換が「○分」形式だけを受け付け、旧チャンネル全21件のコロン形式を出力できていなかった。`minutesToIsoDuration`をMM:SSとH:MM:SSにも対応させた。62:32→PT62M32S、1:10:17→PT1H10M17S。画面やCMSの保存文字列は変更しない。不正な秒・時刻形式や未定の入力は推測で変換せず省略し、従来の「206分(上映版100分)」の変換も維持する。
