# 検証手順

1. `pnpm --dir cms test` と `pnpm --dir cms run typecheck` を実行する。
2. 保全DBへ新migrationを適用し、旧下書き・履歴・公開状態の保持を確認する。
3. 各種別の代表コピーを作成し、保存・再読み込み・公開確認を行う。
4. 検証サイトの本文・リンク・PDF・動画・制作情報を元データと照合する。
5. 履歴参照・復元・再編集・保存を行い、再公開するまで公開内容が変わらないことを確認する。
6. 実施者と結果・未確認範囲を記録する。監督本人の確認と開発者の確認を区別する。

検証CMSには6件の操作確認用コピーを登録済み。新3件の保存形式・DB読み戻しは照合済み。画面から公開した結果と動画/PDF表示・履歴/復元・再編集保存は利用者確認済み。公開・復元操作はDBでも照合済み。
