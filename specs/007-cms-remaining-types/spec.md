# Feature Specification: お知らせ・メディア掲載・チャンネルの一巡

**Feature Branch**: `codex/issue-445-director-review-preparation`
**Created**: 2026-11-21
**Status**: 保存・公開までの作業範囲は利用者合意済み。公開先は既存表示形式を引き継ぐことで合意済み。
**Input**: #419・#420・#421、操作確認準備 #445。11/22 20時の打ち合わせに向け、代表記事で公開まで一巡する。

## User Scenarios & Testing

### US1 お知らせを更新する (P1)
管理者がタイトル・本文を編集して保存し、検証サイトへ公開できる。代表旧記事18059で本文リンクを保持し、再読み込み後も保存内容を確認する。

### US2 メディア掲載を更新する (P1)
掲載元・掲載号・本文・PDF・作品関連を編集し、検証サイトで出典とPDFを読める。代表旧記事17839を使用する。

### US3 チャンネルを更新する (P1)
YouTube・制作年/国/時間・本文・作品関連を編集し、検証サイトで動画と制作情報を確認する。代表旧記事17837を使用する。

各ストーリーの独立した受け入れ条件: 一覧→編集→保存→再読み込み→公開→検証サイトで照合→履歴参照→復元→再編集・保存が成功する。

### Edge Cases

空欄の下書き、存在しない添付・作品、不正な動画ID、同時編集、公開失敗、応答不明、URL衝突、復元元の種別違いを確認する。失敗・応答不明時に公開済み内容と履歴を先に更新しない。

## Requirements

- FR-001: 3タイプを独立した種別として扱い、共通の保存・公開・履歴・復元機能を利用する。
- FR-002: 未入力の下書きを保存でき、公開時に必要なタイトル・表示先と参照先を確認する。
- FR-003: メディア掲載の出典・添付、チャンネルの動画と制作情報を保存・公開・復元で落とさない。
- FR-004: コピー元の本文・リンク・画像・PDFを保全する。簡略化は承認済みの装飾のみ。未知の項目を黙って削除しない。
- FR-005: 検証環境のみ変更する。旧URL・本番記事・既存下書きを上書きしない。
- FR-006: 公開成功後にだけ公開状態・履歴をまとめて確定する。復元は下書きだけを書き換える。

### Key Entities

下書き、公開候補、公開履歴、保護された下書き、添付、作品との関連、旧記事の保全記録。

## Success Criteria

3種別各1件以上で受け入れ操作を完了し、元記事と本文・リンク・添付・種別固有項目を照合できる。既存イベント・ブログの保存と公開の確認に失敗がない。本番への変更は0件。

## Assumptions

既存の管理者認証と共通画面を使う。コピーは正式移行ではない。全件移行、本文装飾の完全再現、部分配信、契約変更は別作業。#390・#394・#433は未完のためオープンを維持する。

公開表示: お知らせは一覧本文＋記事アンカー、メディア掲載・チャンネルは既存ディレクトリの個別ページ。お知らせに新しい個別ページやURL入力欄を増やさない。
