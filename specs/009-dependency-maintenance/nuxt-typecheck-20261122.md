# 現行Nuxtの型検査と参照整合

対象 #438。main dfa0d1bdcから分岐。依存更新 #436、Astro/CMS依存監査 #437とは分け、現行Nuxtの型と実使用箇所を確認する。本番配信を起動するmainへのマージは今回実施しない。

## 修正範囲

- Nuxt 4 / vue-tsc 3で検出した54件の診断を修正。以前のmain c109d668で確認された25件とは区別する。
- FetchLoadingは展開後の非同期状態を受け取る。画像辞書は未存在を型に反映し、73号棟の画像拡大は画像がある場合だけ開く。
- 年別作品・月別イベント・商品ディスク・写真年月日の参照を、存在確認と型のある反復へ変更。年表の開閉状態はカテゴリ/年/月の組み合わせで管理する。
- チャンネルのサムネイルURL生成を型のある算出値へ移し、テンプレート内の繰り返し変数の診断を解消。URL規則と表示情報は維持する。
- 商品不明時は404にし、カート更新は既存商品を直接参照する。削除対象がない場合に末尾の商品を削除しない。保存済みカートを一度だけ読み出す。
- 写真のタッチ開始時に終了位置も初期化し、直前のスワイプ位置を使った誤移動を防ぐ。空のタッチ配列を参照しない。
- 使用箇所がないPDF viewer部品と専用external設定、重複した旧Customer型を削除。未導入viewer依存は追加せず、実使用中のPDFリンクや購入者の型を保持する。
- `npm run typecheck`を追加。型検査の無効化、依存更新、フォーム/決済仕様の変更は行わない。

## 確認

型検査は診断0件。問い合わせ・SHOPの入力検査3件成功。カートに存在しない商品を削除しても内容と保存状態が変わらないこと、数量変更・削除が別の商品種別を壊さないことの回帰テスト2件成功。

- 修正前後とも静的生成成功（各1503ルート、うちHTML741件）。公開WordPress APIを読み取り、同じ条件で比較した。HTMLのページ集合・本文・通常リンク/画像参照に差分なし。内部バンドルのハッシュ差は本文比較に含めない。
- 監督紹介・イベント・チャンネル・SHOP一覧/商品詳細/カート・問い合わせ・73号棟の8ページを360pxと1280pxで比較。16組すべてスクリーンショットとレイアウトが一致し、対象のローカル画像欠損とブラウザー実行エラーは0件。外部フォント等は両方で通信を遮断した条件。
- 両幅でカート追加→数量変更→再読み込み→削除、商品のスワイプ後のタップで誤移動しないこと、73号棟の年表全開閉（表示行116→226→82）、写真の年/月/前後切替、資料画像の拡大/閉じる操作に成功。決済・メール送信の操作はせず、外部通信とGET以外を検証側で遮断した。
- 生成途中で試した画面確認は動作用資産がまだ揃わなかったため無効とし、上記は両方の生成完了後にやり直した結果。写真送りは複数枚のある2014年9月で確認。

再実行: `cd html`でNode 24を使用し、`npm run typecheck`、`npm run test:forms`、`npm run test:shop-state`。静的生成は公開APIを指定した`NUXT_PUBLIC_API_BASE=https://www.petiteadventurefilms.com/ npm run generate`。画面確認は生成結果をローカル配信し、外部送信を遮断する。

## 反映範囲

ローカルの検査・静的生成・画面操作が対象。決済・メールの実送信、本番配信設定・DNS・契約の変更は行わない。本番の反映確認と全ページの品質適合を意味しない。
