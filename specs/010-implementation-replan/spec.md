# 未完了Issueの棚卸し・再計画

対象: #398。調査日: 2026-11-22。状態: 再計画に基づくIssue・残タスク整理（実装開始・本番操作の承認ではない）。

## 目的

期限にかかわらず、現在OPENの全Issueを当初の目的・完了証拠・残作業から整理し、1件ずつ終了できる計画に直す。親と子の同じ作業を二重計上せず、後から条件を追加して終了点を動かさない。

## 受け入れ条件

- 調査時点のOPEN 38件からの追加・終了を追跡し、現在OPEN 39件を全件掲載して、各Issueの現在地と終了範囲を示す。
- 実作業、親の集約、本人・協議待ち、将来拡張、完了整理候補を区別する。
- 重複には担当を一つ示し、担当がない実作業は別Issueへ割り当て、未決事項を残す。条件を削除して完了にはしない。
- 実行順と依存関係を示し、日程や全体完成を推測で約束しない。
- #390・#394・#433はOPENを維持。完了済みIssueを再開しない。
- 本番配信・DNS・契約・決済・メール送信を変更しない。相談事項と未確認を残す。

## 境界

この作業では計画資料とIssue・Projectの対応を整理する。証拠を確認した完了候補は個別判定し、一括クローズ、実装、移行実行は含めない。Issue本文・Projectへ適用する変更は plan.md の適用手順で扱う。既存の採用済み設計（#413など）は維持し、担当を一本化する。
