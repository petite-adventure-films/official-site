# 仕様・設計の案内

Spec Kitの `specs/<番号>-<機能名>/` に要件・設計・タスクをGit管理する。番号は作成順の識別子であり、依存順序やIssue番号とは別。文書の状態と対象Issueは各文書を参照する。

## CMS

- [共通基盤・共通操作](002-cms-foundation/spec.md)：認証、新規作成、保存、複製、履歴・復元、画面共通操作
- [イベント編集](001-event-draft/spec.md)：開催情報・タグ・イベント固有の表示
  - [実装計画](001-event-draft/plan.md)
  - [確認手順](001-event-draft/quickstart.md)

SHOPなどの仕様を追加する際はこの一覧で領域別に案内する。共通ルールはその正本への参照を置き、機能ごとの文書へ転記しない。
